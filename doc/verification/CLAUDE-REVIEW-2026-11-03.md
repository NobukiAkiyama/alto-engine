# Claude Codeレビューと修正（2026-11-03）

対象は `codex/versioning-image-editing`。基点は `aa1a3fd28977bec196f665675426792ee036b606`。
Claude Code 2.1.235（既定モデル `claude-sonnet-5`）を非対話・読み取り専用で実行した。
初回のRust中心のレビューに続き、SDK・Worker・Playgroundの追加レビューを行った。
修正後には `versions.rs` 全体と変更した検証・SVG・SDK・回帰試験を再レビューし、追加の実害ある欠陥はないという結果だった。
旧形式の互換性と後続Phase Dはレビュー対象外として明示した。

## 指摘への対応

| 指摘 | 検証と対応 |
|---|---|
| ラスター範囲とタイル実体の読み込み時検証 | 通常のopenには既に全ノード検証があり、その経路も欠落しているという初回の指摘は該当しなかった。一方、復旧の遅延読み込みでは境界検証を省いていたため修正した |
| SVGの極小数値による一時文字列の増幅 | 実際にRustの通常表記が302〜326 bytes、指数表記なら6 bytesになることを確認。数値の受け入れ範囲を狭めず、図形生成・パス正規化の一時表記を指数表記へ変更。円弧のflagはSVG文法どおり `0` / `1` を保つ |
| SDKの `cancelMerge` が操作順序を追い越す | 他の履歴操作と同じ編集キューへ載せるよう修正。awaitせずにprepare/cancel、finish/cancelを連続呼び出ししても順序を保つ回帰試験を追加 |
| snapshotパッチの参照同一性 | 基点の同じ実装に存在し、今回の変更ではなかった。新規の実害も未確認のため、本PRの修正へ混ぜていない |
| メモリとフォルダproviderの既存object比較の差 | File System Access側のskip動作は既存実装。読み込み・GCでのハッシュ検証とは分けて扱い、今回の追加不具合とは判定しなかった |

画像範囲と**交差しない**タイルは文書グラフ検証で拒否する。画像境界をまたぐタイルは有効であり、境界外の画素がゼロであることを検証する。
復旧では表示前に境界タイルを復号して検証し、内部タイルの遅延復号を維持する。
ラスター・マスク・選択の実体形式も復旧時に確認する。作業文書と保存済みの各版へ同じ検証を適用する。

追加したnative回帰試験は、通常openと復旧openでの不正な境界画素の拒否、正しい部分タイルの保存往復、範囲外タイルの拒否、極小値を多数含むSVGの一時文字列上限と座標維持を扱う。
画像編集・版管理のブラウザ試験には、マージ操作の連続呼び出しを追加した。

## 検証と証跡

レビュー対応後にnativeのengine 65件・doc 24件、native/WASM workspace clippy、SDK build/API check/Node 44件を実行した。
ブラウザの8スイート（274件）とCIと同条件のベクター比較（1フレーム・10ケース）も再実行して成功した。

Claude Codeの生出力とローカル検証ログは `verification/out/claude-review-2026-11-03/`（gitignore対象）へ保存する。
Claudeによるコードレビュー自体はテスト実行を含まない。テストは実装側で行い、GitHub CIの結果はPR checksを証跡とする。
PR作成・CI完了までが今回の実施範囲であり、mainへのマージやタグ・リリース公開は含めない。
